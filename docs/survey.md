## 2. `mato` 컨테이너 — 해독 완료 ✅

**839개 파일**이 이 포맷이다. 확장자가 아니라 매직으로 찾았다.

```
0x00  'mato'
0x04  u32  총 크기 (파일 크기와 일치)
0x08  u32  N = 블록 수
0x0C  u32  0
0x10  u32 * (N+1)   블록 경계. 블록 i = [off[i], off[i+1])
```

전부 **빅엔디언**. 구현은 `tools/mato.py`.

**검증: 839개 전수 파싱 통과, 문제 0건.** (총크기 일치 / 경계 단조증가 / 헤더~첫블록 갭 <16B)

블록 수 분포: N=1 이 441개, N=3 103개, N=21 86개(대부분 `.FCH`), N=4 74개.

### 2.1 블록 안의 2단 구조

블록 머리에 또 `(데이터시작 절대오프셋, 크기, 개수)` 로 보이는 u32 3개가 온다.
`.MSG` 는 이게 **BE u32 절대 오프셋 표 + NUL 종단 cp932** 였다. 다른 확장자는 미확정.

## 3. 텍스트 — 확정 / 하한

### ⚠️미확정: 게임 본편 대사의 위치

`.EVE` 73개(8.3MB)를 cp932 로 훑으면 `懽懽懽` `劔劔劒` 같은 **반복 패턴만** 나온다.
평문 대사가 아니다 — 압축이거나 그래픽/스크립트 바이트다.
전략 RPG 분량을 생각하면 `.MSG` 17,025자가 전부일 리 없으므로 **본편 대사는 아직 못 찾았다**.

⛔확장자별 cp932 스캔 합계(209만자)는 **대부분 노이즈**다. 번역 분량으로 쓰지 말 것.
